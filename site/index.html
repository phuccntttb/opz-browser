On stillness in a world of too many buttons

Every time we open a browser, we’re met with toolbars, icons, suggestions, news, and a search box eager to know what we want. Most of it is never clicked.

Perhaps a good tool is one that knows when to disappear, so that what’s left on the screen is the thing we actually came to read.

Features

Everything is still there. It just waits its turn.

Opz takes nothing away from Firefox. It only decides what belongs in front of you, and what can wait.

Vertical, collapsed tabs

Just a slim column of icons. Hover to expand, move away and it folds back.

A floating address bar

Small and centered while you read. Click it and it rises into a card, with your bookmarks first as you type.

Private by default

Private tabs and containers live right in the tab menu. No telemetry, no account required.

Firefox underneath

Same engine, same extensions, same security fixes. Its profile stays separate from your Firefox.

Privacy

What Opz doesn’t have.

A browser should do one thing: open the web. Everything else is switched off before you launch it for the first time.

0usage data sent home
0sponsored items on New Tab
0AI features running in the background
  • Telemetry
  • Remote studies
  • Sponsored Top Sites
  • New Tab stories
  • VPN, Monitor & Relay promos
  • Extension recommendations
  • Firefox View
  • Default browser nags
  • Default bookmarks

Most of it is only off by default. Turn anything back on in about:config.

  • Version 159.0.1

  • Size 130 MB
  • Auto-updates Yes

Or download the .zip and extract it into your user folder, such as %LOCALAPPDATA%, so Opz can update itself without admin rights. Not code-signed yet: the first time, SmartScreen asks; choose More info → Run anyway.

  • Version 159.0.1
  • Platform Linux · x86_64
  • Size 82 MB
  • Auto-updates Yes

Or download the .tar.xz and extract it anywhere you can write to. install-desktop.sh adds Opz to your app menu, no root needed.

# download
$ curl -LO https://github.com/phuccntttb/opz-browser/releases/latest/download/opz-mac.dmg

# copy into Applications
$ hdiutil attach -quiet opz-mac.dmg && ditto /Volumes/Opz/Opz.app /Applications/Opz.app && hdiutil detach -quiet /Volumes/Opz

# launch Opz
$ open -a Opz
# download (PowerShell)
> curl.exe -LO https://github.com/phuccntttb/opz-browser/releases/latest/download/opz-win64.zip

# extract into your user folder
> Expand-Archive opz-win64.zip $env:LOCALAPPDATA -Force

# launch Opz
> & "$env:LOCALAPPDATA\Opz\firefox.exe"
# download
$ curl -LO https://github.com/phuccntttb/opz-browser/releases/latest/download/opz-linux-x86_64.tar.xz

# extract and add to the app menu
$ mkdir -p ~/Apps && tar -xJf opz-linux-x86_64.tar.xz -C ~/Apps && ~/Apps/opz/install-desktop.sh

# launch Opz
$ ~/Apps/opz/opz
